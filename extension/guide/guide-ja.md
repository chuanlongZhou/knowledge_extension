# GUGA Knowledge · 使い方ガイド

## 1. 収集と整理

サイドバーでノート、ページのスクリーンショット、Todo / Idea、ウェブグループを作成できます。文字を選択して右クリック、または Alt + Shift + S で収集します。記録はブラウザ内にオフライン保存します。画像は Ctrl+V またはファイルから追加でき、録音にはマイクの許可が必要です。添付の保存が完了するまでお待ちください。

タグを記録へ、記録をプロジェクトへドラッグして分類します。記録は複数のプロジェクトに所属でき、プロジェクトには説明、サブプロジェクト、関連図があります。タグの名前・説明・色も同期します。整理済みの記録はプロジェクトへの所属で絞り込めます。

## 2. スタートページと並べ替え

拡張機能が有効な間、Chrome の URL Overrides API により新しいタブに GUGA スタートページが表示されます。＋ または Ctrl+T で開けます。「設定とデータ管理 → スタートページ」で状態とお気に入りの表示数を確認できます。

スタートページには Todo / Idea の全項目を表示し、それぞれスクロールできます。`---` で区切り線を追加し、行末の × で項目や区切り線を削除できます。既存のリストと同じデータで、通常どおり同期します。整理ページまたはスタートページのプレビューで記録を固定すると、お気に入りより上の固定記録欄に表示されます。固定は解除できます。お気に入り 5・8・10 件、未読のウェブグループ、プロジェクトカードも表示します。プロジェクトをクリックすると記録や子プロジェクトを表示します。記録を開いてプレビューし、詳細の編集へ進めます。ダイアログの外側をクリックすると閉じます。Dock には最大 12 サイトを追加し、編集、並べ替え、削除できます。

整理ページは作成日時、更新日時、タグ、プロジェクト、タイトルで並べ替えます。編集直後はカードの位置を保持します。ビューを開き直す、再読み込みする、または再並べ替えで新しい値を反映します。絞り込みや方法の変更時にも再計算します。リストと固定記録は優先表示します。

## 3. ウェブグループ

ページのタイトルや ⠿ を別グループへドラッグすると、そのページだけを既読状態とともに移動します。グループのタイトル、余白、「グループ全体」からドラッグすると、プロジェクトやタグへ記録全体を移動したり、別グループに全ページを統合できます。同じ URL はまとめ、元の本文や分類は保持します。ハンドルをクリックして移動先を選択することもできます。

## 4. Google Drive

自分の Google アカウントでログインします。新規ユーザーはデータフォルダを作成し、新しい端末では同じアカウントでこのバージョンが作成した既存のフォルダを選び、同期ダウンロードします。フォルダを開くボタンで Drive 上の場所を確認できます。

ダウンロードはクラウドから読み取り、アップロードはブラウザの変更を送信します。もう一方を自動実行することはありません。記録とプロジェクトは各 1 JSON、タグは tags.json、添付は別ファイルです。変更のないファイルは検証済みキャッシュを使います。クラウドの整理前に全端末を更新してください。競合はバージョンを選び、ダウンロードで反映します。ブラウザ側を残す場合は続けてアップロードします。

Drive からファイルを削除してもブラウザのコピーは削除されません。添付やプロジェクトの参照先が欠けるとダウンロードできない場合があります。Drive のゴミ箱から復元してください。ログアウトしても記録は保持します。別アカウントや別資料には別の Chrome プロファイルを使ってください。

## 5. バックアップと設定

拡張機能を削除する前に完全 ZIP を書き出してください。プロジェクト別、タグ別、分類なしを選べます。Markdown は元の名前と階層、添付リンクを保持します。複数所属には閲覧用コピーを作り、復元用データは一意に保持します。復元には完全 ZIP を使い、外部で編集した Markdown は復元データにはなりません。JSON 単体は添付の実体を含みません。読み込みは手動アップロードまでローカルのみです。

設定でテーマ、フォント、仲間、サイトの権限、言語を変更できます。English・中文・Français・日本語から選択して適用すると、サイドバーの下書きを保存して現在のページを再読み込みします。他のページは再読み込み後に反映します。Dock のサイトは手動アップロード・ダウンロードで自分の Google Drive と同期し、完全 ZIP バックアップにも含まれます。同時変更時は残す版を選択できます。言語、テーマ、お気に入りカードの表示数はブラウザ内の設定です。自分の記録の内容は翻訳しません。Google 認証情報も書き出しません。更新時は同じフォルダを再読み込みし、先にアンインストールしないでください。
