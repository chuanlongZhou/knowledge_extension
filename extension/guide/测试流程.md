# 简化版验证流程

1. 使用隔离浏览器配置，不删除日常记录。
2. 运行 npm run lint 和 npm test，验证记录、项目、附件与直接同步协议。
3. 运行 npm run test:drive-browser，检查设置、上传下载、冲突和离线备份；该自动化使用模拟的 Google HTTP 服务，不访问真实账号。
4. 运行 npm run test:customization-browser、npm run test:theme-browser 和 npm run test:stability-browser，覆盖筛选、主题与旧数据迁移。
5. 配置 Chrome OAuth 客户端后，在两个真实 Chrome 配置中完成登录、文件夹选择、首次下载、上传、同记录并发冲突与登出验收。自动化通过不能替代此步骤。
6. 运行 npm run build 并加载 dist/pkm-nexus，检查 ZIP 包没有旧的应用安装入口或可执行文件。
