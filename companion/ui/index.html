设置与同步

        
      

      

        
本地资料库

        

          记录保存在 JSON 文件中，readable 文件夹提供 Markdown
          阅读视图。更改记录后可主动导入外部修改。
        

        
        

          
        

      

      

        
连接浏览器扩展

        

          在 chrome://extensions 开启开发者模式，复制 PKM Nexus 的扩展 ID。每台电脑只需配置一次。
        

        
        

      

      

        
自己的 Google Drive

        

          点击登录，在 Google 页面选择你自己的账号。资料同步到该账号拥有的 Drive 资料库，
          每位用户独立授权；应用开发者的 Google Cloud 项目只用于识别应用，不会接收你的资料。
          两台电脑登录同一账号，选择同一个资料库。
        

        

        

        

          
        

        

          
        

        

          
        

        

        

          开发者配置（普通用户无需操作）
          

            应用开发者统一启用 Drive API、创建“桌面应用”OAuth 客户端，并在构建时内置客户端配置。
            这不是开发者的 Drive 授权，也不能内置任何用户令牌。公开使用前需完成 Google
            的发布配置及适用验证。 Testing 模式只允许测试用户，离线授权通常 7 天失效。

自动同步

        
        

          通过 Windows 任务计划执行，关闭 Chrome
          后仍可同步已交接到本地的资料。关机、睡眠和断网期间不执行。关闭此开关会移除定时任务。
        

      

      

        
停止使用本地程序

        
        

          移除本程序的扩展连接和同步任务，保留资料库。随后可从托盘退出助手，再删除程序文件夹。
