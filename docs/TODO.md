  - [ ] 到达上限时只拦截“保存到收件箱”，捕获内容保留为草稿或待处理收集，**不丢失**，并提示先整理；

  - [ ] 同步拉取不受上限限制（其他设备的记录可能使本机超过 50 条），只限制本机新增；
  - [ ] 导入备份时的处理方式。
- [ ] 侧栏和整理页显示“收件箱 n / 50”。
