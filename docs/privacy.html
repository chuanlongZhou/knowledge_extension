隐私政策

本政策说明 PKM Nexus Chrome 扩展与 Windows 配套程序如何处理网页内容、本地资料和 Google Drive 数据。开发者不运营接收知识内容的应用服务器。

收集哪些内容

扩展在用户主动收集时读取网页标题、链接、选中文字或可见区域截图；主动录音时使用麦克风。内容、草稿、图片和录音先保存在本机浏览器存储。网站权限按功能向用户请求。

本地应用

用户连接本地程序后，已保存内容与相关附件复制到所选本地资料库，用于分页、搜索、编辑、冲突处理和开放格式文件阅读。关闭浏览器前未交接的内容需要等待浏览器再次运行。

程序由用户从插件中下载、解压并主动运行，提供小窗口与托盘。扩展不会静默安装或执行程序。自动同步需单独开启，可以关闭。

Google 登录与数据用途

每位用户在 Google 页面登录自己的账号并授权。应用 OAuth 客户端只标识 PKM Nexus，不能代替用户授权。资料同步到实际授权用户自己拥有的专用 Drive 文件夹，不会集中上传到开发者的 Drive。

应用请求 drive.file 权限，仅用于本应用创建或用户明确授权的资料文件。同步会上传记录修订与相关附件，下载另一台设备的修改和按需附件。Google 账号名称、邮箱和 Drive 用户标识用于显示当前账号及防止错误账号同步。

Google API 数据仅用于用户请求的资料管理和同步，遵守 Google API Services User Data Policy 及 Limited Use 要求。不会将这些数据用于广告、出售或自动发送给 AI 服务。

凭证与安全

授权在系统浏览器进行，应用不收集 Google 密码。刷新凭证使用 Windows 当前用户 DPAPI 加密，保存在资料库以外，不进入 JSON 笔记、Markdown、同步批次或备份。切换账号会阻止继续读写原账号绑定的资料库。

知识内容本身使用本机和 Google Drive 的存储保护，并非应用级端到端加密。请妥善保护电脑、Google 账号和导出的备份。

第三方与追踪

本应用没有遥测、广告或自动 AI 调用。用户授权同步时使用 Google Drive；Google 按自己的条款处理托管数据。用户自行打开外部网站、向其他工具提供文件或将资料交给 LLM 时，应另行了解对应服务的隐私处理。

本介绍网站可部署在 GitHub Pages；GitHub 作为网页托管方按其 隐私声明 处理网站访问。本网页不包含额外的分析脚本或追踪器。

关闭、撤销与删除

用户可以关闭自动同步、断开并撤销 Google 授权，或在 Google 账号的第三方连接页面移除授权。管理页可断开本机扩展连接并移除同步任务；退出托盘并删除程序文件夹不会自动删除资料库。

删除当前记录、清空回收站、删除历史修订、远程副本和独立备份是不同操作。同步保留修订用于冲突和恢复，不承诺删除当前记录后所有历史立即消失。完整移除资料时，请分别处理本地资料库、浏览器存储、个人 Drive 文件夹、其他设备及备份；删除远程同步文件前应先备份。

问题反馈与政策更新

通过 项目问题页面 联系维护者，授权相关问题也可使用 Google 授权页列出的支持邮箱。提交公开问题时请避免附带访问令牌、私人资料或完整凭证文件。

功能或数据处理方式改变时会更新本政策与应用内说明，页面顶部标明更新日期。
