个人知识资料库

收集在浏览器，
资料留在自己手里。

保存文字、链接、图片、录音和网页快照。用标签与项目整理，在本地查看开放格式的资料；授权后，通过自己的 Google Drive 在电脑之间同步。

浏览器收集与整理

Chrome 扩展负责收集、编辑、离线保存和备份。未连接本地应用时，也能继续整理。

小窗口与托盘

Windows 配套程序负责本地资料库和同步。最小化或关闭窗口后收进右下角托盘，正常运行无需终端。

自己的 Google Drive

每位用户在 Google 页面独立登录、授权，资料保存到该用户拥有的专用文件夹。开发者不会集中接收用户资料。

开始使用

  1. 加载 PKM Nexus 扩展，在设置中下载内置的 Windows 本地应用。
  2. 解压完整 ZIP，运行 PKM-Nexus.exe，连接自己的扩展。
  3. 登录自己的 Google 账号，创建或选择个人 Drive 资料库。
  4. 需要后台同步时，再明确开启每小时自动同步。

Google 授权服务需要完成应用发布配置。应用注册不等于 Google 审核通过，当前开放状态以授权页面为准。

可读、可备份

正文以 JSON 与 Markdown 保存，附件保存在本机文件夹。版本冲突保留双方；用户可以导出独立备份。同步不能代替备份。

权限、凭证、存储与删除说明见 隐私政策。问题反馈请使用 项目问题页面。
