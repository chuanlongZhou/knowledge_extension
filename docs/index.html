YOUR KNOWLEDGE, GUGUGAGA

收集在浏览器，
资料留在自己手里。

保存文字、链接、图片、录音和网页快照。用标签与项目整理，在浏览器离线查看资料；授权后，通过自己的 Google Drive 在电脑之间同步。

浏览器收集与整理

Chrome 扩展负责收集、编辑、离线保存和备份，不需要配套程序。

手动上传与下载

同步下载读取云端，保存到浏览器；同步上传只发送新增与修改。每条记录一个 JSON 文件，图片和音频单独保存。

自己的 Google Drive

每位用户在 Google 页面独立登录、授权，资料保存到该用户拥有的专用文件夹。开发者不会集中接收用户资料。

开始使用

  1. 加载 GUGA Knowledge 扩展，在浏览器收集和整理。
  2. 在设置登录自己的 Google 账号，创建或选择个人 Drive 数据文件夹。
  3. 新设备先同步下载，编辑后再同步上传。
  4. 定期导出完整 ZIP，保留独立备份。

Google 授权服务需要完成应用发布配置。应用注册不等于 Google 审核通过，当前开放状态以授权页面为准。

可读、可备份

正文以 JSON 与 Markdown 导出，附件随完整 ZIP 保存。版本冲突保留双方；用户可以导出独立备份。同步不能代替备份。

权限、凭证、存储与删除说明见 隐私政策。问题反馈请使用 项目问题页面。
