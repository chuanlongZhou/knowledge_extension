# 标签、项目与项目内关系图

当前实现：0.6.2（2026-10-17）。本说明取代早期的项目关键词设计。

| 概念   | 数据与用途                                       | 操作                                                           |
| ------ | ------------------------------------------------ | -------------------------------------------------------------- |
| 标签   | 单层、多选的内容分类；一条记录可以同时有多个标签 | 左侧显示可换行的标签块，将标签拖到记录上追加；不会替换已有标签 |
| 项目   | 有目标与描述的记录集合；一条记录可以属于多个项目 | 将记录拖到项目文件夹，或使用“加入项目 / 管理项目”              |
| 子项目 | 项目只有一个父项目，组成树；禁止自身引用和循环   | 新建子项目，或编辑项目选择父项目；父子项目不自动继承成员       |
| 关系图 | 每个项目独立维护稳定 ID 的无向关系及可选说明     | 点击“连线”后选择两个节点，或拖动节点连接点；关系可编辑、删除   |
| 喜爱   | 记录的收藏状态，与标签、项目、置顶独立           | 卡片或预览中点“喜爱”，左侧“喜爱”集中浏览                       |

## 当前层级的边界

项目 P 的图只包含：直接加入 P 的记录，以及 P 的直接子项目。子项目在父图中是一个整体节点，不展开其内部记录。

例如 P 中有记录 A、B 和子项目 C，C 内有记录 D。父图允许 A—B、A—C、B—C；禁止 A—D。进入 C 后只能操作 C 本层的节点和关系。两个不同项目中的同一对记录可以有不同的关系说明，互不影响。

图节点由 `Record.project_ids` 和 `Project.parent_project_id` 推导，避免成员清单与节点清单分歧。项目保存 `graph.edges`，每条边有独立 `id`、`source`、`target`、`label`；端点都是稳定记录或项目 ID。`graph.positions` 按节点 ID 保存拖动后的坐标。

## 浏览与整理

- 点击记录先进入只读预览。普通记录可选“简单修改 · Markdown”或“完整修改”；编辑已有记录只显示当前类型。
- 清单保持唯一并在记录列表置顶，不再占一个导航入口。逐行输入文字并按 Enter，Todo 显示复选框，Idea 显示条目，`---` 显示分隔线；底层保存 Markdown，可展开源码；已有项目 ID 与完成状态保留。
- 网页组的单个网页可删除、恢复；删除会划线并保留 URL、标题和条目 ID，不会移除整个记录。
- 页面快照卡片显示图片。未缓存的远程图片可点击加载。
- 项目在标签上方，重复检查与回收站放在底部。重复检查展示相同正文或重复保存的纯链接，不提供新增记录入口。
- 项目图提供占满窗口、指针位置的滚轮缩放、平移、节点拖动、点击预览、交互连线，以及子项目进入 / 返回。节点可直接编辑人工总结，子项目节点编辑描述，右侧预览可进入完整编辑。项目页标题下显示项目描述。从图内进入记录或子项目编辑后，保存、取消或关闭均返回原图，保留层级、缩放、全屏和选中预览。
- 项目描述、颜色、图标和图布局跟随项目数据同步；空标签名称、标签颜色属于本机界面偏好。

标签编辑使用直接点选按钮，可改名和颜色，不提供图标；名称变更原子更新已保存记录、待处理收集和编辑草稿。颜色设置不修改记录修订。项目提供基础图标选择和可见颜色选择器，导航用关系线显示树形结构。

主题、颜色、分区字体 / 字号与导航行距为本机界面偏好，跨扩展页面生效，不改变记录数据，也不随远程资料库同步。

## 保存、移出与删除

项目层级和关系图先在本机保存，正常参与 JSON / ZIP 备份、Companion 交接及 Google Drive 同步。

本机保存、导入和同步合并都会检查循环层级与关系端点。移出项目时，同一事务删除该记录在该项目内的连线，并保留其他项目和标签。删除记录或合并来源记录也清理其连线；还原记录不会恢复已清理的连线。

含有未删除子项目的父项目不能直接删除，应先移动或删除子项目。移动子项目时，清理它在原父图中的连线，其内部关系不变。

跨电脑同时修改导致合并后的父子关系或端点不一致时，同步会停止并保留本机变更；需要先修正相关项目归属或关系再重试。关系与布局按项目记录的版本处理，不做实时多人协作。

## 兼容旧数据

旧项目保留原 ID、记录成员与历史数据，显示为顶层项目。读取不改变其哈希；首次修改项目、关系或布局时升级为 v5，移除已停用的关键词字段。关键词不再出现在当前界面，也不再用来自动或手动生成项目关联。

四种内容记录继续兼容 v4；使用喜爱或网页划线删除时升级为 v5。所有参与同步的电脑应使用 0.6.2 或更高版本。请更新原扩展加载目录并重新加载，保留原浏览器数据库。
